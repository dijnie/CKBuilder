## Shared Pudge Testnet wallet

From the repository root, run `npm ci` and then `npm run wallet:testnet` to create the shared wallet or sync its public address. The command prints the address and faucet URL. The private key remains in `testnet-wallet/pudge.key`, which Git ignores.
